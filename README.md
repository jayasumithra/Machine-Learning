# Machine Learning Laboratory Experiments

## 📘 About

This repository contains the **Machine Learning Laboratory Experiments** performed as part of the undergraduate engineering curriculum.

The repository includes practical implementations of various **Machine Learning concepts, algorithms, data preprocessing techniques, classification methods, model evaluation techniques, and applications**.

Each experiment is organized separately for easy access and reference.
