How Grad-CAM Works in Chest Radiography Screening
Deep neural networks are often described as "black-box" models. Grad-CAM (Gradient-weighted Class Activation Mapping) produces visual explanations by computing gradients of the target screening class score with respect to the feature maps of the final convolutional layer (top_conv in EfficientNetB0):
  • Gradients: Computed via tf.GradientTape to quantify each feature map's contribution to the prediction.
  • Guided Global Pooling: Averages spatial gradients into importance weights \(\alpha_k^c\).
  • Linear Combination & ReLU: Sums weighted feature maps and applies Rectified Linear Activation to isolate features that positively endorse the screening target.
  • Overlay: Scaled up and superimposed onto the original radiograph using a Jet colormap.
